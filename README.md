# SalesPilot AI – AI Voice Sales Bot

SalesPilot AI is an intelligent voice-based sales assistant. It enables real-time conversations with customers, explains SaaS products, answers questions, and automatically analyzes sales interactions.

## Technologies Used

- **Frontend:** React, TypeScript, Vite
- **Backend:** Node.js, Express
- **AI Integration:** Google Gemini Live API
- **Audio:** Web Audio API, MediaRecorder
- **Database & Storage:** Local storage, server storage, optional Supabase
- **Version Control:** Git & GitHub

## Key Features

- Real-time two-way AI voice conversations
- Live conversation transcription
- Call recording with customer consent
- AI-generated call summaries and insights
- Automatic sales status classification
- Call history with recording playback
- Sales analytics dashboard

## How to Run

1. Clone the repository.
2. Install dependencies: `npm install`
3. Create a `.env` file and add `GEMINI_API_KEY=your_api_key`
4. Start the application: `npm run dev`
5. Open `http://localhost:3000`

**Requirements:** Node.js 24 or later and a valid Gemini API key.

## Testing

Run `npm test`, `npm run lint`, and `npm run build` to verify the project.
